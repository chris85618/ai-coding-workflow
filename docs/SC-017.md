# SC-017: Git Hook 自動格式化驗證

## 場景 1: 安裝鉤子後包含 Ruff 指令
- **GIVEN**: 開發者執行 `python scripts/install_hooks.py`
- **WHEN**: 檢查 `.git/hooks/pre-commit` 檔案內容
- **THEN**: 檔案應包含 `python -m ruff format src tests` 指令

## 場景 2: Commit 時觸發格式化
- **GIVEN**: 存在一個格式不正確的 Python 檔案在 `src/` 中且已 `git add`
- **WHEN**: 執行 `git commit`
- **THEN**: Ruff 應被呼叫並修正該檔案的格式
