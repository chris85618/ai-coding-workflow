## ALG-001: 迭代收斂演算法

**描述**：Agent α/β 迭代迴圈的收斂判定邏輯。
**追溯**：FR-012, FR-013 (implements)

```
converge(stage, dimensions[]):
  iteration = 0
  MAX_ITERATIONS = 10  # 硬上限，防止無限迴圈
  
  LOOP:
    findings = agent_α.critique(dimensions, current_artifacts)
    
    # 不動點偵測
    IF all(f.severity == YAGNI for f in findings):
      suggest_termination()
      IF hitl_confirms(): BREAK
    
    improvements = agent_β.resolve(findings)
    
    # 微驗證（每個改善後立即執行）
    FOR each improvement IN improvements:
      result = micro_validate(improvement)
      IF result.FAIL AND retry_count >= 3:
        escalate_to_hitl(improvement)
        CONTINUE
    
    impact = impact_analysis(improvements)
    IF impact.severity == MAJOR:
      escalate_to_hitl(impact)
    
    # HITL 閘門
    choice = hitl_gate()  # [1] 繼續 [2] 加需求 [3] 通過
    IF choice == 3: BREAK
    IF choice == 2: update_inputs()
    
    iteration += 1
    IF iteration >= MAX_ITERATIONS:
      force_hitl("已達迭代上限")
      BREAK
```

**理論保證**：
| 屬性 | 等級 | 說明 |
|------|------|------|
| 終止性 | 🅐 | MAX_ITERATIONS 硬上限保證終止 |
| 不動點偵測 | 🅑 | YAGNI 級啟發式判定，非形式化證明 |
| HITL 可及性 | 🅐 | 每輪迴圈必經 HITL 閘門 |

## ALG-002: 微驗證序列

**描述**：左移微驗證的 6 步執行序列和判定邏輯。
**追溯**：FR-005, FR-006, FR-007 (implements)

```
micro_validate(change):
  MAX_AUTO_FIX = 3
  
  checks = [
    check_structure(change.id),      # Step 1: ID 格式
    check_forward_trace(change.id),   # Step 2: 正向追溯
    check_backward_trace(change.id),  # Step 3: 反向追溯
    check_semantic(change.id),        # Step 4: 語意一致
    check_orphan(change.id),          # Step 5: 孤兒偵測
  ]
  
  FOR each check IN checks:
    IF check.FAIL:
      FOR retry IN 1..MAX_AUTO_FIX:
        auto_fix(check)
        IF recheck(check).PASS: BREAK
      IF still_fail: RETURN FAIL(escalate=True)
  
  # Step 6: 觸發影響分析
  impact = impact_analysis(change)
  RETURN PASS(impact=impact)
```

**理論保證**：
| 屬性 | 等級 | 說明 |
|------|------|------|
| 完備性 | 🅐 | 6 步涵蓋結構、雙向追溯、語意、孤兒、影響 |
| 自主修復 | 🅑 | 最多 3 次，超過強制人工介入 |
| 副作用隔離 | 🅐 | 每步驟獨立，失敗不影響後續 |

## ALG-003: 影響分析爆炸半徑

**描述**：計算修改的影響範圍和嚴重度分類。
**追溯**：FR-008, FR-009 (implements)

```
impact_analysis(change):
  # 正向遞迴展開
  downstream = expand_forward(change.id, depth=0, visited={})
  
  # 反向一致性檢查
  upstream_inconsistent = check_upstream_semantic(change.id)
  
  blast_radius = len(downstream) + len(upstream_inconsistent)
  cross_stage = count_distinct_stages(downstream)
  
  severity = classify(blast_radius, cross_stage):
    IF blast_radius == 0:              RETURN COSMETIC
    IF blast_radius <= 3 AND cross_stage <= 1: RETURN MINOR
    IF blast_radius <= 10 OR cross_stage == 1: RETURN MODERATE
    ELSE:                              RETURN MAJOR
  
  record = IMP(
    id=next_imp_id(),
    change=change,
    blast_radius=blast_radius,
    severity=severity,
    downstream=downstream,
    timestamp=now()
  )
  persist(record, "docs/impact-log.md")
  RETURN record
```

**理論保證**：
| 屬性 | 等級 | 說明 |
|------|------|------|
| 遍歷完備性 | 🅐 | visited set 防止循環，遞迴展開至末端 |
| 分類單調性 | 🅐 | blast_radius 越大嚴重度越高，無逆轉 |
| 持久性 | 🅐 | 每次皆寫入 docs/impact-log.md |

## ALG-004: RICE 優先排序

**描述**：技術債的 RICE 分數計算和四象限分類。
**追溯**：FR-010, FR-011 (implements)

```
rice_score(debt_item):
  reach = count_affected_components(debt_item)  # 1-100
  impact = assess_improvement(debt_item)        # 0.5, 1.0, 2.0, 3.0
  confidence = assess_certainty(debt_item)      # 0.5-1.0
  effort = estimate_person_days(debt_item)      # 0.25-20
  
  rice = (reach × impact × confidence) / effort
  
  quadrant = classify_quadrant(impact, effort):
    IF impact >= 2.0 AND effort <= 2:  RETURN QUICK_WIN    # P0
    IF impact >= 2.0 AND effort > 2:   RETURN STRATEGIC    # P1
    IF impact < 2.0 AND effort <= 2:   RETURN INCREMENTAL  # P2
    IF impact < 2.0 AND effort > 2:    RETURN AVOID        # P3
  
  RETURN (rice, quadrant)
```

**理論保證**：
| 屬性 | 等級 | 說明 |
|------|------|------|
| 排序穩定性 | 🅐 | RICE 為數值比較，總序保證 |
| 四象限完備 | 🅐 | 2×2 分類窮盡所有組合 |
| Sprint 容量 | 🅑 | 20% 容量規則為啟發式 |

## ALG-005: 追溯鏈遍歷

**描述**：正向和反向追溯鏈的遍歷演算法。
**追溯**：FR-005 (implements)

```
expand_forward(id, depth, visited):
  IF id IN visited: RETURN []
  visited.add(id)
  
  children = lookup_downstream(id)
  result = []
  FOR each child IN children:
    result.append((child, depth+1))
    result.extend(expand_forward(child, depth+1, visited))
  RETURN result

expand_backward(id, depth, visited):
  IF id IN visited: RETURN []
  visited.add(id)
  
  parents = lookup_upstream(id)
  result = []
  FOR each parent IN parents:
    result.append((parent, depth+1))
    result.extend(expand_backward(parent, depth+1, visited))
  RETURN result

verify_chain(id):
  forward = expand_forward(id, 0, {})
  backward = expand_backward(id, 0, {})
  
  ASSERT len(backward) > 0 OR id.prefix == "BG"  # 源頭免除
  ASSERT len(forward) > 0 OR id.prefix == "TC"   # 末端免除
  RETURN PASS
```
