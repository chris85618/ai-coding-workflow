# FEA-023: 測試結構對齊與品質硬化

## 1. 摘要
重構 `tests/` 目錄結構以完全對齊 `src/agentic_workflow/` 的物理結構，消除命名空間衝突，並建立嚴格的品質檢查標準（Ruff, Mypy, Pytest）。

## 2. 追溯
- **上游**: BG-005 (品質保證)
- **需求**: FR-047, FR-048, FR-049
- **風險**: RISK-006 (測試路徑斷裂)

## 3. 驗證準則 (Acceptance Criteria)
- [x] `tests/` 目錄下不再包含 `agentic_workflow/` 子目錄（避免 namespace clash）。
- [x] `tests/` 目錄結構與 `src/agentic_workflow/` 保持 1:1 對稱。
- [ ] **單一類別原則 (One-Class-Per-File)**：每個測試檔案僅包含一個測試類別。
- [ ] **高內聚低耦合**：同功能測試整合，異功能測試拆分。
- [ ] `python -m ruff check tests` 通過。
- [ ] `python -m mypy tests` 通過。
- [ ] `python -m ruff format tests` 已執行。
- [ ] `python -m pytest tests` 通過率 100%。
