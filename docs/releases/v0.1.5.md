# Release v0.1.5 — Clean Architecture & DDD Hardening

## Summary
This release completes the comprehensive refactoring of the Agentic Workflow system into a Domain-Driven Design (DDD) and Clean Architecture pattern.

## Key Changes
- **Domain Layer**: 
  - Implemented `Pipeline` as an Aggregate Root with strict invariant enforcement.
  - Extracted `Stage` as an Entity and multiple Value Objects (`Findings`, `SymbolDef`, etc.).
  - Introduced Specification pattern for `BlastRadius` classification.
- **Application Layer**:
  - Implemented pure Use Cases for all workflow operations.
  - Introduced Port interfaces for repositories and reasoning engines.
- **Infrastructure Layer**:
  - Implemented `MarkdownPipelineRepository` for document-based persistence.
  - Integrated `AnthropicReasoner` adapter with LangChain.
- **Quality**:
  - Achieved **100.00%** test coverage (Statement & Branch).
  - Standardized 30+ type-hinting and docstring issues (Ruff/Mypy clean).
