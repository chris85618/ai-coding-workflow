# ADR Template — LLM 撰寫指南

> 本文件為所有 ADR 類別的統一範本。LLM 撰寫時依類別選擇對應區塊。
> 所有欄位皆為必填，除非標記 `(optional)`。

---

## 通用範本（所有類別共用）

```markdown
# ADR-{CATEGORY}-{NNN}: {標題}

> **狀態**: Proposed | Accepted | Superseded | Deprecated | Amended
> **日期**: {ISO 8601}
> **類別**: STRUCTURAL | GOVERNANCE | SECURITY | SCOPE | GATE | OPERATIONAL
> **決策者**: HITL | AI-Proposed+HITL | AI-Autonomous
> **追溯**: {上游 ID 列表，逗號分隔}
> **取代**: {被取代的 ADR ID} (optional)
> **被取代**: {取代本 ADR 的 ADR ID} (optional)

---

## 背景

- 觸發 Stage/Phase：{Phase N / Stage N / 治理層}

- 前置條件：{進入此決策點時的系統狀態}
```

## LLM 撰寫規則

1. **禁止省略欄位**：所有必填欄位必須填寫，若無資料填 `N/A`
2. **追溯完整性**：追溯欄位必須列出所有相關上游 ID，不可泛稱
3. **人類 Prompt 原文記錄**：SCOPE 和 GATE 類別必須逐字記錄人類輸入
4. **影響分析必須執行**：寫入 ADR 前必須計算爆炸半徑
5. **替代方案至少 2 個**：除 GATE 類別外，必須列出至少 2 個替代方案
6. **後果必須雙面**：正面和負面後果各至少 1 項
7. **語言一致性**：與專案主要語言一致（繁體中文或英文）
8. **檔名格式**：`ADR-{CATEGORY}-{NNN}.md`，所有類別一致使用前綴（STRUCTURAL = `ADR-STR-xxx`）
