# ADR-GOV-029: 全面禁止 pragma: no cover (if __name__ == "__main__" 除外)

| 欄位 | 值 |
|------|-----|
| **ID** | ADR-GOV-029 |
| **標題** | 全面禁止 pragma: no cover (if __name__ == "__main__" 除外) |
| **狀態** | accepted |
| **類別** | GOVERNANCE |
| **優先等級** | Critical |
| **背景** | 為了確保專案內部的程式碼品質與可靠性，測試覆蓋率必須真實反映實際執行路徑。任何透過 `# pragma: no cover` 隱式規避測試覆蓋率檢查的手段，皆可能遮蔽潛在的邏輯缺陷或未驗證之分支，屬於高風險行徑。 |
| **決策** | 1. **全面禁用原則**：在整個專案程式碼庫（包括 `src/` 與其他工作目錄）中，全面禁止使用 `# pragma: no cover` 註解。<br>2. **唯一豁免區間**：唯一允許使用 `# pragma: no cover` 的地方，僅限於 `if __name__ == "__main__":` 入口區間，用以規避 CLI 或腳本入口在單元測試中的覆蓋要求。<br>3. **靜態合規掃描**：擴充 `CleanArchitectureBoundaryScanner` 以對程式碼進行物理行掃描。若偵測到未經豁免的 `pragma: no cover`，應將其視為嚴重違規 (`pragma_no_cover_abuse`) 並回報失敗。<br>4. **不妥協覆蓋率**：當覆蓋率不足時，必須以撰寫真實、具備充足測試邊界的 Test Cases 進行覆蓋，而非使用 pragma 註解進行屏蔽。 |
| **後果** | 1. 確保 100% 覆蓋率的真實性與高可靠度。<br>2. 防止開發人員利用 pragma 繞過測試驗證。<br>3. 在 CI/CD 中主動攔截非法的 pragma 繞過行為。 |
