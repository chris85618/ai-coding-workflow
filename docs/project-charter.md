## 商業目標

### BG-001: 建立代理式開發的單一事實來源

**描述**：將所有代理式開發工作流配置、技能路由和治理規則集中管理在一個版控倉庫中，消除跨工具的配置碎片化。

**成功指標**：所有 AI Agent（Antigravity, Claude Code, Cursor）皆從同一份 AGENTS.md 讀取管線定義。

**風險等級**：Impact(4) × Probability(2) = 8（中等）

### BG-002: 確保可追溯、可審計的開發生命週期

**描述**：透過強制 ID 系統和雙向追溯矩陣，使每一個需求、設計決策、測試案例之間的關聯可驗證、可審計。

**成功指標**：任意 TC-xxx 可在 5 步內追溯回 BG-xxx，零孤兒 ID。

**風險等級**：Impact(5) × Probability(3) = 15（高）→ HITL 關注

### BG-003: 透過 HITL 閘門最大化自主代理可靠性

**描述**：在每個 Stage 的出口設置人在迴路確認閘門，防止代理自主決策跨越人類監督邊界。

**成功指標**：零未經 HITL 確認的 Stage 轉換。

**風險等級**：Impact(5) × Probability(1) = 5（低）

### BG-004: 整合久經驗證的結構化分析方法

**描述**：將 Vibe Coding 的 S2C 轉換方法、Red Team 挑戰、RICE 優先排序等已驗證的結構化分析手法，吸收進現有的迭代式雙代理管線。
