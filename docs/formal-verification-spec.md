## 1. Verification Strategy

| Method | Coverage | Tool |
|--------|----------|------|
| deal decorators | Every public method pre/ensure, every stateful class inv | Runtime enforcement |
| deal lint | Every deal-decorated function in src/ | Static contract well-formedness (TC-CONTRACT-001) |
| crosshair-tool (`--analysis_kind deal`) | Every deal-decorated method | Symbolic execution / Z3 (TC-CONTRACT-004) |
| deal.cases + hypothesis | ALG-001, ALG-004 contract fuzzing | Property-based fuzzing (TC-CONTRACT-002/003) |
| State machine model check | SM-001..004 | crosshair + manual proof |
| TLA+ spec gate | Pipeline v2 state machine (Init/Next/safety) | docs/formal/PipelineStateMachine.tla + TLC when installed (TC-TLA-001~005) |
| Z3 SMT proofs | INV-001, INV-026, FR-071 arithmetic invariants | z3-solver unsat counterexample proofs (TC-Z3-001~005) |
| Coq theorems | INV-001, INV-026, FR-071 over unbounded integers | docs/formal/PipelineInvariants.v + coqc when installed (TC-COQ-001~005) |

**Requirement**: Every method in CLS-001..018 must have at least one deal decorator.

**Snapshot semantics note**: deal has no `OLD` snapshot mechanism (unlike icontract). Postconditions
that referenced pre-state are re-expressed as (a) equivalent post-state predicates, (b) `deal.reason`
exceptional contracts, or (c) construction guarantees (e.g. monotonic advance is pinned by asserting
the predecessor stage is PASSED). `deal.inv` additionally validates on *every attribute assignment*,
which left-shifts invariant enforcement to mutation time.

## 2. INV → deal Mapping

### INV-001: Pipeline Sequence Monotonic

```python
# domain/aggregates/pipeline.py — CLS-001
@deal.pre(lambda self: self.status == PipelineStatus.RUNNING)
@deal.ensure(
    # Advancing always lands one slot past a freshly PASSED stage, which pins
    # the post-state of the monotonic move without an OLD snapshot.
    lambda self, result: (
        _stage_order.index(self.current_position) > 0
        and self.stages[_stage_order[_stage_order.index(self.current_position) - 1]].status == StageStatus.PASSED
    )
)
@deal.raises(ValueError)
@deal.reason(ValueError, lambda self: _stage_order.index(self.current_position) >= len(_stage_order) - 1)
def advance(self) -> None: ...
```
