## 利害關係人登記

### S-001: 開發者

**角色**：Primary User / Decision Maker
**利益**：高效、可靠的代理式開發環境；消除重複配置；確保品質和安全
**影響力象限**：High Power + High Interest → **Manage Closely**
**溝通**：每次 HITL 閘門

### S-002: AI 代理群（ECC, gstack, UA, SkillFortify）

**角色**：Technical Consumer
**利益**：清晰的工作流定義、明確的觸發條件、結構化的輸入/輸出規格
**影響力象限**：High Power + Low Interest → **Keep Satisfied**
**溝通**：透過 AGENTS.md + docs/ 結構化文件

### S-003: 未來團隊成員

**角色**：Future User
**利益**：可理解的入職文件、標準化的開發流程
**影響力象限**：Low Power + High Interest → **Keep Informed**
**溝通**：透過 `/understand-onboard` 和 README.md
