# Scope Definition — Antigravity Integrated Workflow System

> **Generated by**: Phase 2.2 (s2c-scope-redteam.md)

---

## In-Scope Features

### FEA-001: 階層式工作流編排

**描述**：AGENTS.md 作為頂層指揮器，呼叫 docs/phases/ 和 docs/stages/ 的階段文件，每個階段文件觸發 skills/workflow-skills/ 的技能。
**追溯**：BG-001 (derives)

### FEA-002: ID 系統追溯

**描述**：16 種 ID 前綴的統一追溯系統，支援雙向追溯鏈和語意一致性檢查。
**追溯**：BG-002 (derives)

### FEA-003: 影響分析閘門

**描述**：每次修改自主執行爆炸半徑計算和嚴重度分類的影響分析。
**追溯**：BG-002 (derives)

### FEA-004: 技術債管理

**描述**：獨立的技術債登記冊，RICE 優先排序，四象限分類，20% Sprint 容量規則。
**追溯**：BG-004 (derives)

### FEA-005: 雙代理迭代協議

**描述**：Agent α（破綻發掘）/ Agent β（收斂整合）迴圈，含微驗證 Step M 和 HITL 閘門。
**追溯**：BG-003 (derives)

### FEA-006: SonarCloud 品質閘門

**描述**：Stage 8 強制品質閘門，覆蓋率 ≥80%、零 Critical 漏洞、技術債比率 ≤5%。
**追溯**：BG-004 (derives)

### FEA-007: 三層安全審計

**描述**：應用安全（/cso）+ Agent 安全（AgentShield）+ 供應鏈安全（SkillFortify）。
**追溯**：BG-004 (derives)

### FEA-008: S2C 結構化分析技能

**描述**：13 個獨立技能文件，涵蓋章程生成、利害關係人分析、範圍定義、需求分解、DDD 建模、BDD 場景生成等。
**追溯**：BG-004 (derives)

### FEA-009: 文件驅動開發架構

**描述**：所有產出物記錄至 docs/ 資料夾的結構化層次：governance/、phases/、stages/。
**追溯**：BG-001 (derives)

### FEA-010: 狀態持久化與恢復

**描述**：工作流狀態機持久化（WBS）、結構化迭代紀錄、中斷恢復協議、LESSON 重用機制，確保任何中斷（含更換無記憶 AI）後皆可從斷點恢復。
**追溯**：BG-001, BG-003 (derives)

## Out-of-Scope

| 排除項目 | 理由 |
|---------|------|
| 應用程式碼生成 | 本專案是工作流定義，不是應用程式 |
| CI/CD pipeline 實作 | 僅定義品質閘門門檻，不實作 pipeline |
| 第三方工具開發 | 使用現有子模組（ECC, gstack, UA, SF） |
| GUI dashboard 開發 | 使用 UA 的現有 dashboard |
