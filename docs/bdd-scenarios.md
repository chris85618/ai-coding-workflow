## SC-003: 迭代 Stage 收斂

```gherkin
Scenario: Agent α/β 迭代自主收斂（Step F REACHED）
  Given Stage N 已就緒
  When Agent α 批判後所有發現為 YAGNI 級

  And HITL 收斂確認觸發

  And iterationCount += 1
  And HITL 不觸發

  And Agent α 以新輸入重新批判
```

## SC-005: 影響分析爆炸半徑

**追溯**: UC-005 (covers), INV-012, INV-013 (verifies)

```gherkin
Scenario: COSMETIC 級修改
  Given 修改一個 ID 且無下游
  When 影響分析計算
  Then blast_radius = 0
  And severity = COSMETIC
  And 變更紀錄寫入對應 ADR

Scenario: MINOR 級修改
  Given 修改一個 ID 且下游 ≤ 3 且同 Stage
  When 影響分析計算
  Then severity = MINOR [INV-012]

Scenario: MAJOR 級修改觸發 HITL
  Given 修改一個 ID 且下游 > 10 或跨 2+ Stage
  When 影響分析計算
  Then severity = MAJOR
  And 系統自動上報 HITL [INV-013]
  And 變更紀錄寫入對應 ADR

Scenario: 嚴重度單調性
  Given 兩個修改 A (blast=5) 和 B (blast=15)
  When 分別計算嚴重度
  Then severity(B) ≥ severity(A) [INV-012]
```

## SC-010: 從斷點恢復工作流

**追溯**: UC-010 (covers), INV-001, INV-018 (verifies)

```gherkin
Scenario: 成功從斷點恢復
  Given workflow-state.md 存在
  And Pipeline Position = Stage 5
  And Stage 3, Stage 4 Gate Status = ✅
  When Session 開始並偵測到進行中工作
  Then 恢復摘要呈現（位置/閘門/待辦/上報）
  And HITL 選擇 [1] 從斷點繼續
  And 工作流從 Stage 5 繼續
  And 已通過的閘門（Stage 3, 4）不重做 [INV-018]
  And Pipeline Position 不倒退 [INV-001]

  Given workflow-state.md 存在
  And 有 1 筆 pending ESCALATION
  When Session 開始
  Then 恢復摘要優先顯示上報項
  And HITL 先處理 ESCALATION
  And 處理後再決定繼續位置

Scenario: workflow-state.md 損壞時從 ADR 重建
  Given workflow-state.md 存在但格式損壞（缺少 Pipeline Position）
  When Session 開始並偵測到損壞
  Then 系統從 Gate Status 和 docs/ 產出物推斷位置
  And 重建 workflow-state.md
  And 報告重建結果予 HITL

Scenario: HITL 選擇重置
  Given workflow-state.md 存在
  And Pipeline Position = Stage 3
  When HITL 選擇 [3] 重置
  Then 系統確認重置意圖（二次確認）
  And 重置後 Pipeline Position = Phase 0
  And 已通過閘門全部清除
```

## SC-011: 全鏈影響追溯

**追溯**: UC-011 (covers), INV-009, INV-019 (verifies)

```gherkin
Scenario: 修改 FR 後驗證 ADR 仍然成立
  Given FR-005 被修改
  And FR-005 被 ADR-GOV-003, ADR-GOV-004, ADR-GOV-006 justifies
  When CrossLinkTracer 執行全方向追溯
  Then 讀取 ADR-GOV-003, ADR-GOV-004, ADR-GOV-006 完整文件
  And 驗證 3 個 ADR 語意仍成立 [INV-019]
  And 驗證連結類型語意合理 [INV-009]
  And CrossLinkReport 無 Violation

Scenario: 修改導致 ADR 不再成立
  Given FEA-xxx 被大幅修改
  And ADR-STR-001 justifies 該 FEA 的架構決策
  When CrossLinkTracer 發現 ADR-STR-001 前提已不成立
  Then ADR-STR-001 標記 SUPERSEDED [INV-019]
  And EVT-007 CrossLinkViolationDetected 觸發
  And HITL 被通知需要新 ADR
  And severity 升至 MAJOR

Scenario: 修改導致 NFR 被違反
  Given CLS-006 被修改
  And NFR-002 constrains CLS-006 的設計
  When CrossLinkTracer 發現 NFR-002 不再被滿足
  Then Violation 記錄 type = NFR_VIOLATED
  And severity 升至 MAJOR
  And HITL 被通知

Scenario: 橫向追溯含 RISK 連結
  Given RISK-004 mitigates FEA-006
  And FEA-006 的 FR 被修改
  When CrossLinkTracer 執行全方向追溯
  Then RISK-004 的應對動作被重新驗證
  And 若應對動作不再有效則報告
```
