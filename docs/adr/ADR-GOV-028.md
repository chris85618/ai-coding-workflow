# ADR-GOV-028: 專案文件入口規範與 README 重構

| 欄位 | 值 |
|------|-----|
| **ID** | ADR-GOV-028 |
| **標題** | 專案文件入口規範與 README 重構 |
| **狀態** | accepted |
| **類別** | GOVERNANCE |
| **優先等級** | Medium |
| **背景** | 隨著專案成熟，原本的 `README.md` 承載了過多底層架構細節，不利於新加入開發者快速上手。同時，由於專案實施了高度自動化 (Git Hooks, SSOT)，需要在入口文件中明確指引。 |
| **決策** | 1. **重構入口**：將舊有架構細節移至 `docs/ARCHITECTURE.md`。<br>2. **新手導向**：新的 `README.md` 應聚焦於 Clone 流程、環境建置、自動化鉤子安裝及快速上手。<br>3. **治理宣示**：在入口處明確揭示 OO Mandate 與 零容忍 警告政策。 |
| **後果** | 1. 降低專案進入門檻 (Onboarding Cost)。<br>2. 確保開發者從第一天就正確安裝自動化守衛腳本。<br>3. 入口文檔與底層架構文檔職責分離。 |
| **追溯** | FEA-020, FR-043 |
| **建立日期** | 2026-05-16T10:51+08:00 |
