# Skill: 雙 Agent 迭代迴圈

> **觸發條件**：Stage 3-8 的每一輪迭代
> **輸入**：該 Stage 的審查維度表、前輪產出物
> **輸出**：改善後的產出物（已通過微驗證、已達 AI 不動點）

---

## 核心變更：AI 自主收斂優先

> AI 必須自主持續迭代直至達不動點，**然後**才彙整全貌交給人類。
> 人類不在每一輪迭代中介入，僅在 AI 收斂後做最終判定。

---

## 執行協議

```
┌────────────────────────────────────────────────────────────┐
│  AI 自主收斂迴圈（無 HITL，持續迭代至不動點）              │
│                                                            │
│  Step A: Agent α（破綻發掘者）                             │
│  ─────────────────────────────                             │
│  1. 載入該 Stage 的審查維度表                              │
│  2. 逐維度對當前產出物進行窮盡式批判                       │
│  3. 對每個發現標注：                                       │
│     - 嚴重度：CRITICAL / HIGH / MEDIUM / LOW / YAGNI       │
│     - 影響範圍：哪些 ID 受影響                             │
│     - 建議方向（不是解法，是方向）                         │
│  4. 產出：問題清單（按嚴重度降序排列）                     │
│  5. 寫入 docs/iteration-log.md                             │
│                                                            │
│  Step B: Agent β（收斂整合者）                             │
│  ─────────────────────────────                             │
│  對 Agent α 的每個問題，依序執行決策流：                   │
│  1. 分類：是 bug / 設計缺陷 / 遺漏 / 風格 / YAGNI？       │
│  2. 奧卡姆剃刀：最簡方案是什麼？                          │
│  3. 前提窮盡：修復前提是否完整？是否有隱含假設？           │
│  4. 併吞分析：此修復能否順便解決其他問題？                 │
│  5. 循環依賴破解：修復是否引入新的循環？                   │
│  6. 邊界內化：修復後的系統邊界是否更清晰？                 │
│  產出：完整自包含改善文件（不引用外部內容）                │
│  寫入 docs/iteration-log.md                                │
│                                                            │
│  Step M: 微驗證迴圈（每個改善後立即執行）                  │
│  ────────────────────────────────────────                  │
│  → 觸發 skills/workflow-skills/micro-validation.md         │
│  → 觸發 skills/workflow-skills/impact-analysis-exec.md     │
│  → 全數通過才進入不動點判定                                │
│  → 任一失敗 → 自主修復 → 重新執行 Step M                  │
│  → 修復 3 次仍失敗 → 上報至 HITL（ESCALATION 類型）       │
│                                                            │
│  Step F: 不動點判定                                        │
│  ─────────────────                                         │
│  IF Agent α 本輪所有發現的嚴重度皆為 YAGNI:               │
│    → fixed_point = REACHED                                 │
│    → 進入 Step C（HITL 收斂確認）                         │
│  ELIF 本輪 Agent α 的 CRITICAL + HIGH 數量                │
│       ≥ 前輪 CRITICAL + HIGH 數量:                        │
│    → fixed_point = DIVERGING                               │
│    → 停止自主迭代，進入 Step C（需人類方向指引）          │
│  ELSE:                                                     │
│    → fixed_point = NOT_REACHED                             │
│    → 更新 docs/iteration-log.md                           │
│    → 更新 docs/workflow-state.md (iteration round++)      │
│    → 回到 Step A                                          │
│                                                            │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  Step C: 👤 HITL 收斂確認（僅在不動點/發散時觸發）        │
│  ──────────────────────────────────────────────            │
│  呈現完整收斂報告：                                        │
│  - 總迭代輪次                                              │
│  - 每輪 Agent α 的嚴重度分佈趨勢                          │
│  - 最終殘餘問題（僅 YAGNI 級，或發散原因）                │
│  - 產出物完整清單及追溯狀態                                │
│  - 建議：通過 / 需人類指引                                 │
│                                                            │
│  使用者選擇：                                              │
│  [1] 加入新需求/方向後繼續 → 更新輸入 → 回到 Step A      │
│  [2] 通過 ✅ → 進入出口閘門驗證                          │
│                                                            │
│  若使用者選 [1]，AI 再次自主收斂（完整迴圈重啟）          │
└────────────────────────────────────────────────────────────┘
```

## 出口閘門驗證（通用模板）

通過 HITL 後，執行出口閘門驗證：

```
出口閘門 = 該 Stage 的原有檢查項
         + 追溯矩陣驗證（見 TRACEABILITY.md）
         + 影響分析完成確認
         + 所有文件已寫入 docs/
         + docs/workflow-state.md 已更新（移除已完成 leaf）

全數通過 → 進入下一 Stage
任一失敗 → 回到 Step A 繼續迭代（AI 自主收斂）
```
