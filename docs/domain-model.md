## 聚合與類別

### CLS-001: Pipeline（聚合根）

**描述**：工作流管線的頂層編排實體，管理 Phase/Stage 序列和轉換。
**追溯**：UC-001, UC-003 (models)

```
<<aggregate root>>
Pipeline
  - phases: Phase[5]
  - stages: Stage[6]
  - currentPosition: PhaseOrStage
  - status: PipelineStatus {NOT_STARTED, IN_PROGRESS, COMPLETED}
  + start(): void
  + advance(hitlConfirmation: HitlChoice): void
  + getCurrentPosition(): PhaseOrStage
  [INV] phases 和 stages 序列不可重排
  [INV] advance() 僅在 HITL ✅ 後可呼叫
```

### CLS-002: Stage（值物件）

**追溯**：UC-003 (models)

```
<<value object>>
Stage
  - number: int {3..8}
  - dimensions: Dimension[]
  - iterationCount: int
  - status: StageStatus {PENDING, ITERATING, PASSED}
  + runIteration(artifacts: Artifact[]): IterationResult
  + checkFixedPoint(findings: Finding[]): bool
  [INV] number ∈ {3, 4, 5, 6, 7, 8}
  [INV] status 只能單向轉換: PENDING → ITERATING → PASSED

### CLS-003: IterationLoop（領域服務）

**描述**：Agent α/β 迭代迴圈的執行引擎，實作 ALG-001。
**追溯**：ALG-001 (implements), UC-003 (models)

```
<<domain service>>
IterationLoop
  + execute(stage: Stage, artifacts: Artifact[]): StageResult
  - agentAlpha(dimensions: Dimension[], artifacts: Artifact[]): Finding[]
